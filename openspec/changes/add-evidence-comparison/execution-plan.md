# Продолжение CMP после реализованного среза

Планирование от 26.09.2026. Это порядок реализации остатка C06, не утверждение
о выполнении новых задач. Разделы 1–5 tasks.md и evidence.md остаются историей
11 завершённых задач. Исходные пять операторов, persistence и pipeline не
переписываются. Актуальный ID уже разделяет документы, редакции, области и
периоды; протокол читает настоящие группы доказательств.

| Этап                   | Задачи  | Самостоятельный проверяемый результат                                                                 | Зависимости                                                    |
| ---------------------- | ------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| A. Основания величин   | 6.1–6.3 | Нормализованное число, явная единица/provenance, unknown без угадывания; backward-compatible контракт | Ранний этап A add-reviewed-matrix-release, существующие ID/EXT |
| B. Численная семантика | 7.1–7.4 | Явные преобразования, допуски/границы, сохранённая неопределённость и трасса                          | A; подтверждённая численная политика конкретного правила       |
| C. Pipeline и UI       | 8.1–8.3 | Версионированная публикация, читаемая причина отказа, scalar-leaf для C07                             | B; существующие RabbitMQ/Run/протокол                          |
| D. Приёмка             | 9.1–9.2 | Воспроизводимый отчёт реального корпуса и сохранная история                                           | C; разрешённые исходники и ожидаемые контрольные точки         |

Полный выпуск правил 132/132 из C18 зависит от приёмки этого оператора;
обратной зависимости от финального выпуска нет. C07 использует новый
scalar-leaf после C, а его schema/fixtures можно готовить после A. GEO
передаёт только реально полученную опору и неопределённость; CMP не создаёт
погрешность из confidence. EVENT использует общие snapshots/verdicts без
обязательного численного преобразования там, где оно не нужно.

Предметные неизвестности ведутся по параметру: допуск, округление,
процент/доля, нулевой expected и источник единицы. Они блокируют только
допуск зависимой версии; реализация арифметики, совместимости и независимых
правил продолжается. Исправление P019 и comparison P004 принадлежат C18,
составные ветви P004 — C07/GEO по подтверждённой трактовке.

Готовность этапа D означает пригодность проверенного механизма и перечисленных
правил, а не наличие всех требуемых документов объекта и не точность всех
132 параметров. Счётчики алгоритмического покрытия, выполненных сравнений
и решений инспектора остаются раздельными.
