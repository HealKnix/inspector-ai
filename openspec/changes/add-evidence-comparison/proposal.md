## Why

Первый срез сравнения уже реализован: пять скалярных операторов, вердикты,
доказательства и защита версий; его 11 выполненных задач и evidence сохраняются.
Продолжение устраняет ограничения единиц, преобразования величин, округления и
неопределённости, чтобы численно похожие значения не давали необоснованный вывод.

Источник требований — [итоговый PDF и приложения](../../../docs/requirements/SOURCES.md).
Исторический срез опирался на локализацию параметров по объекту
«Новослободская» (`ОТЧЁТ_параметры_1-132_Новослободская.md` в корне рабочей
области), где для каждого параметра указаны ожидаемый источник матрицы,
фактические места и значения по стадиям.

## What Changes

Новая часть плана: нормализация с сохранением raw, явное преобразование
совместимых единиц, отсутствие единицы без угадывания, документированные
допуски/округление и сохранение неопределённости. Этапы — в
[execution-plan.md](execution-plan.md). Перечень ниже сохраняет границы
реализованного базового движка; повторная реализация не требуется.

- Контракт `RuleVersion.comparison`: типы сравнения `equals`,
  `numeric_delta` (abs/pct), `no_decrease`, `no_increase`, `threshold`.
- Чистый движок вердиктов над членами EvidenceGroup: выбор expected/actual,
  попарное сравнение, явные исходы `match | discrepancy | expected_missing |
actual_missing | expected_ambiguous | actual_ambiguous | not_comparable |
no_comparison`.
- Персист вердикта в `evidence_groups.verdict` с fingerprint набора правил и
  снимком спеки сравнения.
- Переизвлечение артефакта, когда терминальная классификация изменила стадию
  после последнего цикла извлечения (роли и вердикты пересобираются без
  ручного вмешательства).
- API и панель объекта: вердикт, значения обеих сторон, дельта и ссылки на
  доказательства.

## Capabilities

### New Capabilities

- `document-evidence-comparison`: Предварительное сравнение извлечённых
  значений по утверждённой спеке правила с объяснимым вердиктом.

### Modified Capabilities

Нет опубликованных main specs. Используется уже существующая дельта
`document-evidence-comparison`; EXT сохраняет владение извлечением и группами.

## Impact

backend: контракт/движок сравнения, сборка групп и вердиктов, admin-API
правил; frontend: типы и блок сверки в карточке объекта.

Зависимости: EXT (извлечения), ID (подтверждённые редакции и контексты),
ранний этап A `add-reviewed-matrix-release` (паспорт/регрессии правил).
Готовность всего выпуска 132/132 не нужна для развития оператора. Рабочий
протокол/решения принадлежат `add-inspector-verification`; CMP предоставляет
ему предварительный вердикт, сохраняя независимое решение инспектора.

## Non-goals

- Решение инспектора по вердикту, протокол и финализация.
- Автоматическое утверждение предложенной LLM спеки: предложение проходит
  предметный допуск C05/C18.
- Самостоятельный выбор применимой редакции: используется уже реализованный
  снимок ID с отдельными областями/периодами, без возврата к пустому scope.
- Геометрические сравнения и проверки по нормам, требующие контекста
  помимо пары значений.
