### Подтверждённые свойства

- Вердикты пересчитываются по мере готовности сторон: P009 прошёл
  `actual_missing` → `expected_ambiguous` (два ПД-источника с разным
  unit-выводом) → `match` после слияния unitless-членов.
- Три ПД-источника (ПЗ/ПЗУ/АР) с одним значением сливаются в единый
  expected; два РД-источника (КЖ/СВГ) — в единый actual.
- Смена правила (P022 v3, P002 v5) и бамп версий движков меняют
  fingerprint и запускают новый цикл извлечения без ручного
  вмешательства; циклы извлечения на артефактах достигли 7 и все
  succeeded.
- Члены без стадии попадают в группу с `role: unknown` и предупреждением,
  но не участвуют в сравнении.
- `no_evidence`/`ambiguous` на стороне не превращаются в нарушение.

## Ограничения и открытые вопросы

- P055/P061/P062 не заведены правилами: БСС ∅600/∅620 из отчёта относится
  к сваям, а не к P061/P062 (толщина стен/арматура) — маппинг не
  подтверждён; P055 (класс бетона B40 vs B40 F150 W6/W8) требует
  «уточняющей» семантики поверх equals, отложено.
- P002: сид-правило `table_lookup` не сработало — ТЭП в ПЗ/ПЗУ лежит в
  текстовых блоках/нескопленной таблице ГПЗУ. v5 (regex + window_blocks=10)
  извлекает значения; итерации v3 (`\d+` срезал разряд «1401,0»→401) и
  v4 (брал первую десятичную «74,5» вместо проектной колонки) отклонены
  через reject — история версий сохранена.
- Admin-search через curl в Git Bash на Windows ломает кириллицу в
  JSON-теле (CP1251-молоко) — вызовы admin API делать из python/файла с
  явным UTF-8, иначе поиск «не находит» заведомо существующие термины.
- P022 «l» vs «II» — реальный дефект текстового слоя КЖ; решение о
  нормализации римских цифр остаётся за владельцем правила, движок
  честно показывает discrepancy.
- АР (48 с.) обрабатывается долго под нагрузкой парсера; чекпоинты
  сохраняют прогресс, цикл возобновляется автоматически после истечения
  лиза (recover-цикл ~5 с).
- Парсер падал по `models_not_ready_timeout`/`parser_timeout` при
  конкуренции — таймауты изолированного стека подняты до 3600/1800 с
  в `compose.local.yaml`.
