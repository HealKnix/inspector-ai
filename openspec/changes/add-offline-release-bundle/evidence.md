## Состав и воспроизведение

- [Инструкция и контракт подключения следующих модулей](../../../docs/offline-release.md) определяют ранний CPU-профиль Linux/amd64, локальные ресурсы и пределы проверки.
- `scripts/offline/bundle.mjs` собирает поставочные образы, локальные модели/сигнатуры, точный каталог и автономный установщик. Production AppModule и Prisma CLI проверяются под Node до упаковки.
- `backend/scripts/offline-catalog.mjs` экспортирует только справочники и утверждённые исторические правила в `REPEATABLE READ READ ONLY`. Пользователи, документы и решения не копируются. Восстановление проверяет хеш, пустое исходное состояние и роль администратора; выполняется транзакционно под advisory lock. Совпадающий каталог повторно не вставляется и не порождает второе событие восстановления; отличающийся каталог не перезаписывается.
- Manifest связывает 9 image IDs и 15 файлов: образы с миграциями и frontend assets, модельные веса, сигнатуры, каталог, Compose, inventory, инструменты и инструкцию. Проверка целостности предшествует использованию. Asset restore отклоняет traversal, symlink и отличающиеся данные в томах.
- Bootstrap создаёт уникальные локальные секреты, применяет миграции, штатно создаёт начального администратора и восстанавливает каталог. Runtime env отсутствует в manifest и не должен передаваться получателю. Точная версия Node — 24.16.0; Bun 1.4.2 используется для сборки зависимостей.
- Все core-сервисы находятся в Docker `internal` network, runtime build/pull отсутствуют. Frontend публикует только loopback-порт через отдельный ingress bridge; до Nginx устанавливается OUTPUT DROP для IPv4/IPv6, разрешены loopback, ответы и backend:3000. Затем снимаются NET_ADMIN/NET_RAW и включается no-new-privileges. Внешний DNS закрыт; ошибка firewall запрещает запуск.

Manifest r8 SHA-256: `b899ad410f1307ffe767d07c4ec2711750506534e66c912a2a29ef41db0e7692`.
Каталог SHA-256: `69a576ed1a0ef7ed91076ebc26a4ebba746072abbd7692c0f7f1d6a1fd6f9cf1`.

[Итоговая сверка доказательств](../../../docs/offline/evidence/2026-09-27-r8-acceptance.json) связывает девять отчётов их SHA-256, проверяет общий manifest, image IDs, каталог и replay. Секреты в этот реестр не включены.

r8 — исправление установщика/конфигурации поверх r6/r7: теги образов сохраняют `foundations-20260927-r6`, а точные IDs закреплены в manifest. Образы, модели, сигнатуры и каталог не пересобирались при исправлении начальной роли пользователя.

[Manifest](../../../docs/offline/evidence/2026-09-27-r8-manifest.json) и локальный комплект `.test-output/offline/foundations-20260927-r8` относятся к одному кандидату. `static-and-runtime` связывает даты создания всех восьми томов с интервалом между запечатыванием manifest и первой успешной установкой, а также сохраняет фактические image IDs и сети. Рабочая БД `inspector-ai` не мигрировалась и не изменялась.

Независимые доказательства разделены: образы загружаются в отдельный пустой Docker daemon с сетью `none`, а приложение запускается на host daemon на новых томах с теми же image IDs. Это не утверждение, что полный runtime запускался внутри пустого daemon. Установщик вправе пропустить повторный `docker load`, только когда все локальные IDs уже точно совпали; после обеих ветвей IDs проверяются снова.

После трёх синтетических smoke-прогонов replay сохранил 7 пользователей, 3 объекта, 3 назначения, 3 процесса, 3 Run, 3 файла и 3 parse artifacts, 132 строки, 13 rule versions и один framework set. Проверка сравнивает идентичности сущностей и полный каталог; она не заявляет побайтовую сверку всех пользовательских данных. Auth sessions исключены, поскольку login создаёт новую сессию. Fingerprint runtime env остаётся только локально; evidence содержит результат `secret_file_unchanged: true`.

## Исправленные отказы холодного старта

- Исправлен путь Prisma CLI в Node migration image; `ajv` перенесён в production dependencies без смены версии.
- Healthcheck RabbitMQ запускается от пользователя `rabbitmq`: прежний root-healthcheck мог создать Erlang cookie до штатного chown и вызвать отказ чтения при первом запуске.
- Для Docker 29 добавлен защищённый ingress bridge frontend: один internal bridge не обеспечивал публикацию порта.
- В Compose явно указан `nginx -g 'daemon off;'`: переопределённый entrypoint сбрасывал image CMD и завершал frontend без запуска сервера.
- Bootstrap учитывает штатную роль INSPECTOR у новой регистрации; существующая deployment-команда атомарно проверяет отсутствие администратора и назначает начального администратора с аудитом.

Промежуточные r3/r4 evidence оставлены как история, они не используются вместо финального r8. После заполнения C пользователь освободил место и перезапустил Docker. Удаление старых r2–r6 тестовых ресурсов отклонено автоматической проверкой без отдельного согласия пользователя; они сохранены, очистка не входит в критерий OFF-initial.

## Границы раннего допуска и открытые задачи

Ранний gate относится к автономной упаковке существующего ядра и контракту расширения. Он не равен завершению полного OFF change.

- **4.1 остаётся открытым** до полного журнала сетевых обращений за startup/smoke. Фактические firewall/изоляция и отрицательные HTTP/DNS-пробы подтверждают блокировку, но не заменяют такой журнал.
- DOCX smoke проверяет реальную очередь и сохранённый parse artifact; это не измерение точности OCR, качества сравнения или скорости на H100. Полный путь до EXPORT (4.2) остаётся отдельной работой.
- Включены 9 локальных PaddlePaddle-моделей; upstream лицензии/revisions и SHA-256 девяти LFS-весов проверены. Для graph/config сохранены upstream blob IDs/size, неизвестный upstream SHA-256 не выдуман. [Источники](../../../docs/offline-model-sources.json).
- ClamAV содержит main/daily/bytecode, базу 28135 от 26.09.2026; FreshClam отключён. Тестовый EICAR проверяет фактическое обнаружение, а не только наличие процесса. Допустимый возраст базы и обновление следующего выпуска остаются эксплуатационной политикой.
- В исходной БД были 104 версии; переносится только 13 утверждённых записей для 12 параметров, 11 эффективных comparison-правил и 132 строки каталога. Это сохранение provenance, а не повторный предметный допуск или покрытие 132/132. Новые MAT-паспорта/регрессии не экспортируются до утверждения переносимого контракта fixtures (2.2).
- Происхождение/лицензия Placebo Fiera неизвестны; полная задача inventory 1.1 открыта. H100/VRAM/драйвер, действующий локальный LLM endpoint, HYP/GOLD/ML, обновление с recovery и итоговая передача также остаются в своих задачах.
