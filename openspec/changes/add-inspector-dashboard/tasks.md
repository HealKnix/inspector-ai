# C17 — рабочая сводка

H — минимальный путь к реальной проверке; F — полноценный Medium-dashboard.
Источники данных: ObjectAccess, VER, COM, exports, audit, SUSPICION и обмен.
Другие модули не зависят от завершения dashboard.

## 1. H — текущие данные вместо макета

- [ ] 1.1 Зафиксировать список подтверждённых показателей и mapping к API/статусам; проверка: каждый показатель имеет источник/версию/знаменатель, ни один не выведен из макета Workday.
- [ ] 1.2 Добавить недостающие read-only агрегаты с объектным доступом; проверка: две страницы объектов и отзыв назначения не искажают итог и не раскрывают чужие данные.
- [ ] 1.3 Подключить основной экран к назначенным объектам и реальным проверкам; проверка: путь главный экран→объект→upload→verification ведёт к API-данным без demo.
- [ ] 1.4 Разделить coverage, кандидатов, подтверждённые нарушения и пропуски; проверка: 132 строки с частичным выполнением не показываются как 132 успешные проверки.
- [ ] 1.5 Заменить статический SystemStatusPopover проверенным health/актуальностью либо явным отсутствием данных; проверка: недоступный backend не отображается как штатный SLA 24/7.
- [ ] 1.6 Реализовать loading/error/empty/forbidden и очистку кеша при смене доступа; проверка: UI-тесты ошибок и revoke не оставляют чужие значения.

## 2. F — фильтры и межмодульные переходы

- [ ] 2.1 Добавить фильтры раздел/статус/дата в URL и стабильную пагинацию; проверка: reload/deep link восстанавливают выбор, общий итог отдельно от фильтра и страницы.
- [ ] 2.2 Связать выбранную версию с exports и audit; проверка: история/скачивание открывают тот же protocol_id и не переходят незаметно на latest.
- [ ] 2.3 Подключить категории SUSPICION и состояние внешней синхронизации после готовности контрактов; проверка: гипотезы не увеличивают confirmed, PENDING_SYNC не отменяет finalization.
- [ ] 2.4 Проверить клавиатурную навигацию, длинные названия и компактный экран; проверка: сценарии выбора/фильтра/перехода доступны без скрытого обрезания действий.
