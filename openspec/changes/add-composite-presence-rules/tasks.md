- [x] 2.1 Реализовать строгую версионированную валидацию AND/OR/leaf с лимитами узлов/глубины; проверка: неизвестный kind, цикл, лишнее поле и превышение лимита отклонены, код из документа не исполняется.

- [x] 2.4 Сохранять полную трассу и определяющие ветви без потери неисполненных причин; проверка: повтор на одинаковом снимке даёт тот же результат, short-circuit не помечает неизвестную ветвь проверенной.
