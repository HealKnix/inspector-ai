# Геометрия PDF-чертежей

Владелец: P3 CV + P4 проверки. Нумерация локальная; [SRC-x.y] указывает задачу исходного объединённого change, а не её текущий статус. [Карта переноса](../../SPLIT_MAP.md), [общие обязательства](../../SHARED_BACKLOG.md), [контракты](../../CONTRACTS.md).

Все задачи открыты: перенос и готовность планирования не означают реализацию. Backend/frontend/ML выполняются в рамках одного функционального change; завершение определяется его спецификацией.

## 1. Контракты и предпосылки

- [ ] 1.1 Проверить зависимости PAR и C05-C18; закрепить версии входных/выходных контрактов из CONTRACTS.md. Проверка: у каждой используемой сущности и миграции есть один владелец, отсутствующая зависимость явно отмечена.

## 2. Реализация capability

- [ ] 2.1 [SRC-2.7] Подключить capability drawing-geometry-analysis к общим проверкам доступа/аудиту C01 и безопасным событиям/метрикам C23. Проверка: изменение оставляет автора/версию/корреляцию, запрос чужого объекта отклонён, содержимое и секреты отсутствуют в логах; транспорт уведомлений не реализован повторно.
- [ ] 2.2 [SRC-6.7] Реализовать калибровку и измерения PDF-чертежей; проверка: известная линейка даёт измерение с основанием, неизвестный масштаб не даёт достоверного численного результата.
- [ ] 2.3 Реализовать GeometryResult по общей схеме с EXT и сохранение через Node-адаптер. Проверка: результат содержит величину/единицу/опору/locator и версии, повтор не создаёт дубль.

## 3. Интерфейс

- [ ] 3.1 Добавить overlay измеряемого объекта и калибровки в viewer PAR. Проверка: поворот/обрезка страницы не смещают выделения.

## 4. Проверки и доказательства готовности

- [ ] 4.1 [SRC-11.8] Выполнить локальный CV-бенчмарк PDF с версиями, оборудованием, ошибкой и временем. Проверка: отчёт передан C24 и явно не закрывает конфликт DWG без решения владельца.
- [ ] 4.2 [SRC-11.9] Проверить отсутствие/конфликт масштаба, несколько видов, timeout и повтор геометрического job. Проверка: не появляется достоверное число без опоры, старый результат не перезаписывает новый.
- [ ] 4.3 Проверить самостоятельный результат на реальных зависимостях: На чертежах с известной опорой измерение и overlay проверены; неоднозначная опора не даёт ложного значения. Выполнен локальный PDF-бенчмарк, результат не выдан за DWG. Проверка: evidence.md содержит команды, версии, результаты и ограничения; mocks не используются как доказательство закрытия реальной интеграции.
- [ ] 4.4 Выполнить применимые проверки существующего репозитория для изменённых частей (тесты, typecheck, build) и проверку OpenSpec. Проверка: результаты записаны в evidence.md, auth не сломан, отложенные обязательства C24 перечислены без отметки выполнения.
