# Парсинг, OCR и координаты

Владелец: P3 OCR + P2 viewer. Нумерация локальная; [SRC-x.y] указывает задачу исходного объединённого change, а не её текущий статус. [Карта переноса](../../SPLIT_MAP.md), [общие обязательства](../../SHARED_BACKLOG.md), [контракты](../../CONTRACTS.md).

Отметки отражают реализацию и проверки из [evidence.md](evidence.md). Backend/frontend/ML выполняются в рамках одного функционального change; общая приёмка C24 остаётся отдельным обязательством.
