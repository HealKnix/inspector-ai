# Поэтапное продолжение PAR

План от 26.09.2026, состояние обновлено 27.09.2026. Исторические разделы 1–7 [tasks.md](tasks.md) сохраняют свои отметки; они подтверждают реализованный маршрут, а не отсутствие выявленных позднее дефектов. Задачи 8.1–8.4 выполнены: [реализация и фактический прогон](../../../docs/parsing-regressions/implementation-2026-09-27.md). Задачи 8.5–8.8 остаются открытыми; version/cache и компонентные проверки потребителей уже подготовлены, но не заменяют выпуск нового Run и проверку развёрнутого viewer. Требования и исходные связи не заменяются этим планом.

| Этап                        | Задачи  | Последовательность и результат                                                                                    | Условие перехода                                                                                             |
| --------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 1. Контрольный набор        | 8.1     | Зафиксировать исходные артефакты → вручную разметить значения и связи → сохранить манифест/обезличенные регрессии | Пять ошибок единиц, строка материала, лист изменений и растровые сканы воспроизводятся; знаменатели известны |
| 2. Текст и структура        | 8.2–8.4 | Схема происхождения → разрешение перекрытий → восстановление ячеек → доступ к native вне main                     | Исправленные примеры сохраняют исходники и точные локаторы; unknown не получает OCR                          |
| 3. Измерение качества и GPU | 8.5–8.6 | Общий evaluator → CPU baseline → GPU на тех же весах/корпусе → сравнение качества, времени, памяти                | Есть фактический отчёт; недоступный GPU оставляет задачу открытой                                            |
| 4. Безопасный выпуск        | 8.7     | Новый fingerprint/схема → чтение legacy → новый Run → проверка rollback                                           | Старые протоколы и оригиналы неизменны; несовместимый кеш не принят                                          |
| 5. Проверка потребителей    | 8.8     | Реальный PAR→ID/EXT → viewer → регрессии → evidence для C24                                                       | Исправления подтверждены на фактических артефактах, качество не подменено confidence                         |

P3 ведёт алгоритмы, P1 — границу схем/хранилища, P2 — viewer, P4 — разметку. Разметку и подготовку GPU можно выполнять параллельно; downstream-проверка начинается после 8.4 и адаптации контракта ID. Замена OCR-движка и VLM не подразумеваются. Выпуск общего офлайн-пакета относится к add-offline-release-bundle; PAR передаёт веса, версии, fingerprints и проверенные профили. Общее качество и производительность принимаются add-release-acceptance, локальный отчёт их не закрывает.

Ссылки на действия реализации: [design.md](design.md), [спецификация](specs/document-parsing/spec.md).
