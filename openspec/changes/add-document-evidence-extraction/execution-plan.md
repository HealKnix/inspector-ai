# Поэтапное завершение EXT

План от 26.09.2026. Раздел 7 [tasks.md](tasks.md) содержит реализованный срез, а открытые разделы 1–5 — полные обязательства. В частности, наличие 132 строк каталога и 12 исполняемых планов не означает готовности всех правил. Отметки задач сохраняются без переоценки.

| Этап                       | Задачи           | Порядок и выход                                                                                                                          | Приёмка этапа                                                                                                                     |
| -------------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 1. Полный контракт         | 1.1, 2.1, 3.1    | Сверить текущие таблицы/схемы → согласовать типы/единицы/части и владельцев с ID/GEO/C05-C18 → аддитивные изменения                      | Поля происхождения/версий проверяются на границе; таблицы правил не продублированы                                                |
| 2. Семантические кандидаты | 8.1, затем 3.2   | Зафиксировать baseline → измерить локальную модель → добавить версионированный исполнитель → извлечь значения только из найденного proof | На независимых validation-примерах есть числа, единицы, переформулировки, отсутствие и несколько кандидатов                       |
| 3. Доказательные группы    | 3.3–3.4, 8.2–8.3 | Типизированный факт → подтверждённая часть/редакция/область → роли по правилу → GEO adapter → миграционная совместимость                 | Номер пункта не принимается за доказательство; неизвестная калибровка/редакция не допускает сравнение; старый результат неизменен |
| 4. Интерфейс фактов        | 4.1, 7.8         | Переиспользовать существующую админ-карточку и viewer → сверить остаток 7.8 → показать тип, единицу, источник, неоднозначность           | Инспектор видит доказательство, администратор — dry-run; извлечение не становится вердиктом                                       |
| 5. Надёжность и приёмка    | 5.1–5.3          | Смена RuleVersion во время job → повтор/unsupported → реальные PAR/ID/GEO → evidence и проверки репозитория                              | Нет ложного отрицательного результата; версии/fencing и доступ сохранены; отчёт передан C24                                       |

P3 реализует кандидатов/исполнители, P1 — схему и публикацию, P2 — факты/viewer, P4 — эталоны правил. Этап 2 и контракт GEO могут идти параллельно. Фактическое сравнение с GEO начинается только после появления реальных измерений; контрактный fixture не закрывает эту часть.

C05/C18 (add-reviewed-matrix-release) владеет смыслом правил, единицами, операторами и 132/132; EXT принимает их утверждённые версии. Раздел 7.8 может частично совпадать с уже существующим UI: до закрытия проверить всю формулировку, повторный экран не создавать. Производительность и качество корпуса передаются add-release-acceptance; offline bundle получает закреплённые веса и runtime. См. [design.md](design.md) и [спецификацию](specs/document-evidence-extraction/spec.md).
