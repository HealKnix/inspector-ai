## Why

Распознанный документ ещё не содержит типизированных фактов, пригодных для сравнения. Нужен движок извлечения по активным проверенным правилам с единицами, областью и происхождением.

Источник требований — [итоговый PDF и приложения](../../../docs/requirements/SOURCES.md). Исходный объединённый change сохранён в [истории](../../superseded/2026-09-17-add-document-ingestion-and-completeness/proposal.md); перенос требований и задач — [SPLIT_MAP.md](../../SPLIT_MAP.md).

## What Changes

- Типизированные текстовые и табличные извлечения, regex и семантические якоря.
- Контракт RuleVersion и Evidence_Fragments/Checks без присвоения результата предметного сравнения.
- Прослеживаемость до документа/редакции/страницы и передача геометрических результатов через общий контракт.

## Capabilities

### New Capabilities

- `document-evidence-extraction`: Извлечение фактов по правилам.

### Modified Capabilities

Отсутствуют: main specs пока пусты. Путь capability принадлежит только этому активному change.

## Impact

backend/ml extraction, Node validation/persistence Evidence/Extraction, RuleVersion reader; frontend показ фактов и локаторов.

Предлагаемый владелец: P3 извлечение + P4 правила. До завершения требуются: add-document-identification; общие предпосылки C05-C18 из [реестра](../../SHARED_BACKLOG.md). Подготовку по контрактам можно вести раньше реализации зависимости.

## Non-goals

Импорт, формализация и утверждение всех 132 конфигураций принадлежат C05/C18; сравнение — C06/C07, геометрические измерения — GEO. Полное покрытие 132 подтверждается в C18/C24 в том же релизе.

Критерий самостоятельного результата: Движок исполняет утверждённые текстовые/табличные планы, отклоняет неподдержанный тип и возвращает проверяемые факты с версиями. Отдельный реестр C18 сохраняет обязательство всех 132 строк; отсутствие реального модуля сравнения не блокирует проверку самого извлечения.
