# Извлечение фактов по правилам

Владелец: P3 извлечение + P4 правила. Нумерация локальная; [SRC-x.y] указывает задачу исходного объединённого change, а не её текущий статус. [Карта переноса](../../SPLIT_MAP.md), [общие обязательства](../../SHARED_BACKLOG.md), [контракты](../../CONTRACTS.md).

Все задачи открыты: перенос и готовность планирования не означают реализацию. Backend/frontend/ML выполняются в рамках одного функционального change; завершение определяется его спецификацией.

## 5. Проверки и доказательства готовности

## 7. Первый срез: каталог правил и извлечение до панели результатов

Согласованный 19.09.2026 срез реализует в этой же ветке минимальную часть общей зависимости C05/C18 (как часть C01 была реализована в ветке ING). Границы и отступления описаны в design.md: provenance на уровне File+стадия, словари синонимов вместо эмбеддингов, типы планов table_lookup/regex/cascade, 3–8 утверждённых правил вместо 132. Задачи раздела не закрывают одноимённые пункты SHARED_BACKLOG и разделов 1–5 автоматически.
