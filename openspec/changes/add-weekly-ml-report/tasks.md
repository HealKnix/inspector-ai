# C22. Еженедельный отчёт

Владелец: P4 методика, P1 агрегации/планировщик, P2 интерфейс, P3 рекомендации по ML. Формирование можно разрабатывать на VER; полный отчёт использует GOLD/ML, доставка — OBS.

## 1. Период и определения

- [ ] 1.1 Зафиксировать показатели отчёта, знаменатели, версии источников и правила поздних решений. Проверка: ручной расчёт небольшого набора совпадает с ожидаемой сводкой, доля отклонений не названа точностью.
- [ ] 1.2 Добавить конфигурацию timezone, границ недели, получателей и прав чтения. Проверка: расписание без явно заданных параметров не включает отправку, граничное событие входит ровно в один период.

## 2. Срез и агрегации

- [ ] 2.1 Реализовать агрегации решений/причин/уточнений и покрытия данных по зафиксированному срезу. Проверка: фильтры UI и повтор решения не изменяют знаменатели неожиданно.
- [ ] 2.2 Подключить dataset/model versions и фактические metrics ML. Проверка: отсутствующие измерения представлены как неизвестные, а не нулевая или идеальная точность.
- [ ] 2.3 Добавить сохраняемые версии отчёта и идентификатор входного среза. Проверка: позднее событие создаёт новую редакцию без переписывания старой.

## 3. Представление и рекомендации

- [ ] 3.1 Сформировать шаблон отчёта с причинами, категориями, выборкой, версиями и ссылками на основания. Проверка: все числа прослеживаются до сохранённого среза.
- [ ] 3.2 Добавить рекомендации на основе наблюдаемых причин и ограничений выборки. Проверка: пустой/малый набор не даёт неподтверждённых выводов или автоматического запуска обучения.
- [ ] 3.3 Сделать защищённый список/просмотр истории отчётов для назначенных пользователей. Проверка: доступ к отчёту не обходит права на исходные объекты.

## 4. Расписание и доставка

- [ ] 4.1 Подключить идемпотентное недельное задание с уникальностью периода/версии методики. Проверка: рестарт планировщика и повтор сообщения не создают дубли.
- [ ] 4.2 Передавать готовность отчёта в OBS и отображать результат доставки отдельно. Проверка: недоступный канал оставляет отчёт доступным и сохраняет ошибку.

## 5. Приёмка

- [ ] 5.1 Выполнить прогон непустого и пустого периодов с границами timezone и поздними событиями. Проверка: сводки сверены вручную и включены в evidence.md.
- [ ] 5.2 Проверить разрешённую тестовую доставку, права и повторное формирование, выполнить применимые тесты/typecheck/build. Проверка: инструкция воспроизводит отчёт без реальной отправки неутверждённым получателям.
