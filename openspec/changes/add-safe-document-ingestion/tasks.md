# Приём и хранение документов

Владелец: P1 backend + P2 frontend. Нумерация локальная; [SRC-x.y] указывает задачу исходного объединённого change, а не её текущий статус. [Карта переноса](../../SPLIT_MAP.md), [общие обязательства](../../SHARED_BACKLOG.md), [контракты](../../CONTRACTS.md).

Реализация ведётся в feat/safe-document-ingestion; результаты проверок фиксируются в evidence.md. Готовность планирования сама по себе не означает реализацию. Backend/frontend/ML выполняются в рамках одного функционального change; завершение определяется его спецификацией.
