# Поэтапное завершение COM

План от 26.09.2026. Отметки исходных задач сохранены; открытая 5.1 требует реальных выходов всех соседних модулей. Сохранённая история 3.4 подтверждает реализованный срез AND/OR/областей, но полный листовой сценарий получает отдельное продолжение 6.1–6.2.

| Этап                              | Задачи/основание                                               | Шаги и результат                                                                                                   | Критерий готовности                                                                                            |
| --------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 1. Сверка входов                  | Проверка оснований выполненных 1.1–3.9 в составе 5.1           | Сопоставить активный implementation-contract с реальными ID/EXT/GEO и версиями ожидаемого состава                  | Явно видны отсутствующие входы; fixture не назван реальным измерением                                          |
| 2. Листовое покрытие              | 6.1                                                            | Подтверждённый перечень → карта применимых листов ID → сопоставление без подсчёта страниц → новый versioned result | Частичная замена и наследование проверены; неизвестный лист не становится FULL                                 |
| 3. Объяснение в UI                | 6.2                                                            | Дополнить существующие API и таблицу → переход к нужной странице/редакции → legacy чтение                          | Показаны пропуски и неопределённости, версии и серверные счётчики сохранены                                    |
| 4. Реальные межмодульные проверки | 5.1                                                            | Утверждённый состав → PAR/ID → факты EXT/измерения GEO → COM → дозагрузка нового снимка                            | Дубли, старые редакции, неподдержанное правило, отсутствующий proof и unknown scale не дают FULL или нарушение |
| 5. Evidence завершения            | Завершение 5.1 с актуализацией evidence по выполненным 5.2–5.4 | Приложить реальные входы/версии/hash/ожидаемые исходы → применимые проверки изменённых частей → передача C24       | Все заявленные реальные интеграции имеют прогоны; полная релизная приёмка остаётся отдельной                   |

P4 владеет ожидаемым составом и эталонами, P1 — расчётом и API, P2 — объяснениями. UI можно готовить по контракту параллельно с 6.1; завершающий прогон ждёт ID с листами и действующие EXT/GEO. До этого доступные сценарии целых документов остаются самостоятельной проверкой с явно ограниченным охватом.

Исходные 1–4 и 5.2–5.4 не создают второй список реализации: при изменении зависимостей выполняется лишь необходимая регрессия в рамках 5.1/6.1/6.2. Граф затронутых требований принадлежит INC; утверждение всех правил — add-reviewed-matrix-release. См. [design.md](design.md), [tasks.md](tasks.md), [спецификацию](specs/document-completeness/spec.md).
