# Идентификация, редакции и уточнения

Владелец: P3 извлечение + P1 модель + P2 UI. Нумерация локальная; [SRC-x.y] указывает задачу исходного объединённого change, а не её текущий статус. [Карта переноса](../../SPLIT_MAP.md), [общие обязательства](../../SHARED_BACKLOG.md), [контракты](../../CONTRACTS.md).

Задачи разделов 1–5 остаются открыты: перенос и готовность планирования не означают реализацию. Backend/frontend/ML выполняются в рамках одного функционального change; завершение определяется его спецификацией.

Согласованный 18.09.2026 первый сценарий классификации с LLM выделен в раздел 6.
Его завершение не закрывает более широкие задачи разделов 1–5 автоматически.
