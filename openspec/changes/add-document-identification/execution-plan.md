# Поэтапное завершение ID

План от 26.09.2026 сохраняет реализацию разделов 6–9. Полные исходные задачи 1–5 остаются открытыми до сверки с требованиями; их закрытие требует evidence всей формулировки. Ни один проставленный чекбокс не меняется этим планом.

| Этап                         | Задачи tasks.md        | Шаги и выход                                                                                                                                       | Проверка результата                                                                                                           |
| ---------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 1. Контракт остатка          | 1.1–1.3, 10.1          | Сопоставить действующий API/справочники с исходным ID → оформить недостающие правила по частям, листам и визуальным реквизитам → закрепить версии  | Источник каждого решения указан; нет выдуманного правила утверждения, роли или перехода                                       |

P1 ведёт модель/транзакции, P3 — извлечение/границы/визуальные кандидаты, P2 — карточку и viewer, P4 — справочники и эталоны. Разметка, контракт и UI по согласованным схемам параллельны. Этап 4 начинается после решений 10.1 и исправления PAR; неизвестные правила остаются уточнением. Разделы 2–5 уже частично реализованы: сначала сопоставляется фактический код, затем дописывается остаток без второго сервиса или повторных таблиц.

Семантика утверждения по конкретному штампу, полномочия ручного разделения и критерии автоматического принятия требуют подтверждённого основания; этот план не выбирает их за владельца. Независимые задачи 10.2, разметка и техническая сохранность истории могут идти до этих решений. Полный граф пересчёта остаётся INC, комплектность — COM, качество 132 правил — add-reviewed-matrix-release. См. [design.md](design.md), [tasks.md](tasks.md) и [спецификацию](specs/document-identification/spec.md).
