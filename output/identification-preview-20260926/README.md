# Документы и редакции — скриншоты текущего интерфейса

Снято 26.09.2026 с настоящих компонентов текущего React-приложения. API и документы — явно обозначенные синтетические данные для демонстрации. Это не результаты анализа пользовательского корпуса и не подтверждение обновления рабочего стенда.

Просмотр: http://127.0.0.1:4173/objects/11111111-1111-4111-8111-111111111111/documents?processId=33333333-3333-4333-8333-333333333333&runId=44444444-4444-4444-8444-444444444444

Вход в приложении: Объекты → нужный объект → Загрузка комплекта документов → ИИ-помощник → Документы и редакции. В узком окне блоки расположены вертикально; в широком реестр находится слева от карточки.

Скриншоты сняты в обычном узком окне встроенного браузера без изменения размеров viewport и без графической обработки. Preview не выполняет POST-запросы; кнопка создания запуска показана до отправки.

Воспроизведение из корня inspector-ai: `node .test-output/identification-preview.mjs`. Данные находятся в `.test-output/identification-preview-data.json`, локальные вспомогательные файлы исключены из Git. Нужны установленные зависимости проекта. Остановить preview можно завершением соответствующего Node-процесса.
