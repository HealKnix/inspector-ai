Диагностические ГИ и ГИ-изм3 разрешены текущей задачей пользователя и относятся к отдельному `authorised-diagnostic-regression`. Их нет в организаторском TRAIN_PUBLIC manifest; они не объявлены ни public train, ни hidden test. Source hashes: `04dcef6bbc217d7e0dad28097dc11e885022a169c7c2f037efa8968474f3aacb` и `b8b03fee48855b066fd27eb0c46c832cf2755870857208213eaebb5c33fc709f`. Они доступны локально через `.test-output/real-documents-20260926/manifest.json` и соседний `tmp/ocr-audit-20260926`, но не копируются в Git.

В листе изменений сохранены все 46 исходных IDs, bbox и routing flags. В восьми блоках проектный шифр, имена и описание/адрес заменены явным `[REDACTED]`; список находится в fixture. Для этих восьми блоков проверяется доступность и сохранность геометрии, а marker не является эталонной транскрипцией. QR и изображения подписей не входят в PNG. Полный исходный срез 46 блоков существует локально; отсутствие личного текста в коммитном fixture является заявленным преобразованием, а не отсутствием исходника.

Растровые страницы 8 и 9 — оригинал F0152, SHA-256 `99ec972d7dfe5039fca922e3120bd5e486f2a26518f78044d0850992c028e7af`. Использованы только оригинальные изображения и самостоятельная транскрипция, без overlay и организаторских ответов. Два фрагмента одного документа не являются независимой выборкой.

Документы/ответы `OBJ-RECHNIKOV-7-7` не открывались. Исторически известные диагностические примеры и public train не переименованы в независимый validation или hidden.

## Формат для реализации и воспроизведение

`input_candidates` содержит только native-блоки и реальные OCR text-блоки с числовым confidence. Исторические OCR-агрегаты с `confidence=null` исключены: они уже содержат смешанный текст и не являются новым наблюдением. `cell`/`row_cells`/`table_cells` — неизменённый старый результат, включая ошибки и пустые значения. Его нельзя использовать как исправленный input gold. Bbox всех блоков использует исходную `visible-page-normalized` систему координат; bbox PNG crop сохранён в manifest.

Запуск из корня репозитория, Python с `pypdfium2`:

```text
python docs/parsing-regressions/build_diagnostic_fixtures.py
python docs/parsing-regressions/build_public_raster.py
python docs/parsing-regressions/verify_fixtures.py --originals --report docs/parsing-regressions/verification.json
```

Для проверки уже включённого набора без локальных оригиналов достаточно `python docs/parsing-regressions/verify_fixtures.py`. Генераторы хешируют итоговые байты, поэтому JSON/PNG после генерации не следует отдельно переформатировать. Изменение fixture требует повторного manifest и визуальной проверки. `.local/` содержит только исключённые из Git previews; они не являются поставочными fixtures.

`prepare_runtime_inputs.py` создаёт игнорируемый `.test-output/par-native-ocr-20260927-inputs.json`: три проверенных оригинала, четыре страницы, пути хоста и `/inputs/`. Он предназначен для отдельного координируемого прогона настоящих моделей. Веса, параметры моделей и результаты этого прогона данная задача не меняет.
