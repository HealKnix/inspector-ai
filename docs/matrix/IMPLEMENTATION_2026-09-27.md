Браузер показал форму входа вместо ошибки подключения. Административные экраны проверены компонентными/API-тестами; браузерный сценарий после входа на этой сборке не выполнялся.

Начальная попытка диагностического скрипта ошибочно передала полные PDF (8/9/77 страниц) вместо четырёх выбранных. Два файла завершились, 77-страничный — нет (`models_not_ready_timeout`, сохранённый прогресс 17/77 после `parser_unavailable`). Этот результат не удалён и не засчитан как успех.

Прогон выявил реальную несовместимость транспорта: `timeout: false` для Bun не отключал пяти­минутное ожидание заголовков Node fetch. `postParser` использует native HTTP с ограниченным сигналом общего времени файла; health/progress/cancel сохраняют короткие пределы. Тесты покрывают задержку заголовков, отмену, обрыв body и отказ переноса авторизации по redirect. Полный 77-страничный документ после исправления не прошёл повторную приёмку; нагрузочная проверка остаётся открытой.

Исправленный smoke готовит только разрешённые страницы через `prepare-smoke-excerpts.py`: для всех четырёх подтверждены одинаковые render pixels и native text с оригиналом. Фрагмент связан с SHA-256 полного источника и исходными номерами страниц. Скрытый набор не использовался.
