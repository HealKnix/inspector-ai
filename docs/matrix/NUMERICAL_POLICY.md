# Точная численная политика

Реализуется существующими EXT/CMP и серверным MAT runner. Версии: `extraction-engine-v3`, `comparison-engine-v3`, `decimal-v1`, `decimal-units-v1`, `metric-units-v1`. Старые планы читаются в прежней форме; новый допуск численного правила требует явной политики. Это технический контракт, не источник нормативных допусков.

`number_policy` задаётся в regex-плане либо в `table_lookup.value`: `version`, `mode: single|first`, `reject_list_marker`, `require_unit`. Для новых кандидатов используется single. Число сохраняется десятичной строкой, исходный текст отдельно. Несколько чисел в одной ячейке не сводятся к первому. Единица должна принадлежать выбранному значению, строке или заголовку выбранного столбца и иметь собственный локатор. Строгие результаты не заимствуют единицу соседнего совпадения. Номер пункта и разделители проверяются до нормализации.

`numerical_policy` сравнений содержит `target_unit`, `zero_expected: absolute_only|not_comparable`, `allow_percent_fraction`, `rounding: null|{scale,mode}` и версию. Режимы округления: half_up, half_even, toward_zero. Если округление применяется, паспорт содержит JSON этой политики и подтверждённое основание ветви. Допуски и границы принимают ограниченную десятичную строку; для точного эталона следует использовать строку. `numeric_delta` требует явные допуски и inclusive; threshold — границы с min_inclusive/max_inclusive. Нулевое ожидаемое значение не получает процентный допуск по догадке.

Whitelist содержит метрические длины, площади, объёмы, массу, напряжение, счётные единицы и процент/долю. Перевод выполняется как точная степень десяти с сохранением множителя. Процент/доля требуют отдельного разрешения. Неизвестная единица, несовместимая размерность или отсутствие доказательства дают not_comparable. Без единицы допускается только явно заданная безразмерная величина `target_unit: "1"`.

Неопределённость представлена интервалом с отдельным основанием. OCR confidence не является погрешностью измерения. Если интервал пересекает границу и однозначный вывод невозможен, результат неопределённый. Разности сохраняются строками; относительная разность — точной дробью numerator/denominator, без выдачи округлённой бесконечной дроби за точное значение. Числовые delta/delta_pct остаются только для совместимого отображения.

`ordered_category` использует явные map_version, ranks, direction и basis. Само написание «II», «С345» или число в обозначении не задаёт порядок. Неизвестный член справочника даёт not_comparable. Предметный порядок должен быть подтверждён отдельно для конкретного правила.

Трасса хранится в `verdict.pairs[].trace`, исходная численная информация — в `Extraction.numerical` и членах неизменяемой доказательной группы. Регрессия сравнивает и эту информацию с вручную заданным ожиданием. Для PDF сохраняется bbox; для структурных форматов допустим structural_path. Старым результатам трасса не достраивается.

Проверки: exact-comparison.test.ts, extraction-engine.test.ts, matrix-regression.test.ts, matrix-review.test.ts. Синтетические проверки арифметики не подтверждают приёмку P019 или остальных строк на реальных документах.
